# Automation specs

This directory stores durable implementation specs created by the local issue automation loop.

Each automated issue gets a folder:

```text
docs/automation/specs/issue-0003-short-slug/
  requirements-review.md
  spec.md
  adversarial-review.md
  test-plan.md
  security-notes.md
  ux-evidence.md
  screenshots/
```

Automation must not implement an issue until the spec is reviewed by an adversarial reviewer and approved by a trusted maintainer.
